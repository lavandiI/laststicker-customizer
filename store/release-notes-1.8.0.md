# LastSticker Customizer 1.8.0

Релиз про надёжность и скорость: индексация доводится до конца, поиск перестал
ходить по всему индексу ради первой страницы, а интерфейс стал доступнее.

## Что нового

### Надёжность индексации

- Состояние запущенной индексации хранится в `chrome.storage.session`: после перезапуска
  service worker расширение узнаёт о работающей задаче, а не теряет прогресс и результат.
- Результат задачи пишется в `chrome.storage.local`: панель обновляет статистику, статус и
  ошибки по подписке на хранилище, поэтому кнопка больше не остаётся в состоянии
  «Индексация…» после потерянного ответа.
- Offscreen-индексатор раз в 10 секунд отправляет heartbeat, чтобы браузер не усыплял
  service worker между батчами.
- Добавлено разрешение `unlimitedStorage`: индекс диалогов больше не упирается в квоту
  `chrome.storage.local` (5–10 МБ в зависимости от версии Chrome).
- Сбой записи метаданных (время индексации, флаг полного индекса, отчёт автообновления)
  больше не превращает успешно сохранённый индекс в сообщение об ошибке.

### Скорость

- Поиск по форуму останавливает сканирование, как только нашёл страницу результатов плюс
  одно совпадение; панель вместо придуманного итога показывает «Показаны первые N совпадений».
- «Показать ещё» догружает следующую страницу по `offset`, а не перечитывает весь набор.
- Панель кэширует разобранный индекс: ввод в поиске больше не перечитывает и не парсит все
  сообщения заново.
- Звёздочки в аукционах загружают список избранного после простоя страницы, кешируют набор на
  5 минут и обходят не более трёх страниц вместо двадцати.
- Переход к сообщению из старого результата идёт пачками по 10 страниц, с бюджетом в шесть
  секунд и отменой по новому клику.

### Доступность

- Результаты поиска размечены как список (`listbox` → `group` → `option`), поле ввода —
  как `combobox` с `aria-expanded`: навигация стрелками и выбранный результат объявляются
  скринридером.

### Тёмная тема

- Счётчик непрочитанных больше не печатается белым по оранжевому: контраст 6,6:1 вместо 2,8:1.
- Ячейки с неизвестным инлайновым фоном перекрашиваются, а не оставляют серый текст на светлом.
- Печать снова читаема: палитра сбрасывается на светлую.
- Палитры «Чёрная» и «Сапфир» перекрашивают акцентные поверхности, а не оставляют графитовые пятна.
- После выключения расширения кэш первого кадра обновляется — страница больше не мигает тёмным.

### Исправления

- Счётчик сообщений в списке диалогов больше не принимает дату вида `12/2024` за количество
  сообщений; ложное число могло привести к пропуску изменившегося диалога.
- Даты распознают сокращения «май» и «сент».
- Подсветка запроса работает для запросов с `&`, `<`, `>` и кавычками.
- Фильтр «Я ищу» не портит счётчик чек-листа и переживает перерисовку таблицы.
- Двойной клик по двум строкам одного лота больше не отправляет два запроса в toggle-эндпоинт;
  неудачный клик объясняет причину.
- Настройки темы не сбрасываются при ошибке чтения хранилища.

## Установка

- Вручную: скачайте `laststicker-search-1.8.0.zip`, распакуйте и загрузите папку через
  `chrome://extensions` → «Загрузить распакованное расширение».
- Обновление поверх 1.7.1 сохраняет индекс и настройки: они привязаны к ID расширения.

## Файл

- `laststicker-search-1.8.0.zip`
- SHA256: смотрите в описании релиза (сборка на Linux, детерминированная).

## Примечание

Это первый релиз с разрешением `unlimitedStorage`. Ревью Chrome Web Store сверяет набор
разрешений с листингом; обоснование добавлено в `store/listing-ru.md` и в политику
конфиденциальности.
