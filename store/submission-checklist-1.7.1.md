# Публикация LastSticker Customizer 1.7.1 в Chrome Web Store

## 0. Текущее состояние

- В Store опубликована **1.6.3**.
- Черновик **1.7.1** загружен и сохранён в Dashboard; он заменил черновик 1.6.4. На проверку не отправлен.
- Версия **1.7.1** подготовлена в ветке `release/1.7.1`; она включает все изменения 1.6.4, 1.7.0 и 1.7.1.
- Коммит подготовки: `d13d6b8`.
- ZIP: `dist/laststicker-search-1.7.1.zip`, 481 142 байта, SHA256 `58E0B348DB111465AB5180612036649F5D1EE13DE5F43692984806E41023F9FA`.
- GitHub release **v1.7.1** опубликован; ZIP прикреплён. Для Store используйте именно этот ZIP из релиза: локальная сборка на Windows может отличаться только CRLF/LF и иметь другой SHA.
- Новых разрешений нет: `storage`, `scripting`, `offscreen`, `alarms`, host permissions для `laststicker.ru` и `www.laststicker.ru`.
- Подробное описание: `store/description-1.7.1.txt`.
- Что нового: `store/whats-new-1.7.1.txt`.
- Описание карточки: `store/listing-ru.md`.
- Политика: `PRIVACY.md`, `docs/privacy.html`.
- Release notes для GitHub: `store/release-notes-1.7.1.md`.
- Промо: `store/promo-440x280-1.7.1.png`, `store/marquee-1400x560-1.7.1.jpg`.
- В Dashboard обновлены название, краткое и подробное описание и пять скриншотов; черновик сохранён.
- **Не отправлять на проверку без отдельного согласования.**

## 1. Проверить версию и собрать ZIP

```bash
git checkout release/1.7.1
npm ci
npm test -- --runInBand
npm run lint
npm run package
```

Проверить:

- в `manifest.json` и `package.json` версия **1.7.1**;
- ZIP: `dist/laststicker-search-1.7.1.zip`;
- внутри `manifest.json` в корне и версия 1.7.1;
- внутри есть `auction-favorites.js`, `collections-filter.js`, `collections-filter.css`, `welcome.*`, `theme.*`, `popup.*`, `scroll-widget.*`, `icons/black/*`;
- нет файлов трекинга, тестов, `node_modules` и лишних разрешений;
- размер и SHA256 совпадают с `store/release-notes-1.7.1.md`;
- для Store используйте ZIP из GitHub release v1.7.1 (каноническая сборка workflow на Linux). Локальный `npm run package` на Windows может дать другой SHA из-за CRLF/LF.

## 2. Загрузить пакет и заполнить карточку

1. Открыть Chrome Web Store Developer Dashboard → LastSticker Customizer (URL карточки может оставаться `laststicker-search`).
2. Проверить, что обновлённая политика уже опубликована по Store URL (`docs/privacy.html` на GitHub Pages): в ней должны быть страницы коллекций и аукционов, фильтр и звёздочки. Иначе ревьюер увидит старую политику.
3. Проверить, что в разделе **Пакет** черновик **1.7.1**, а не 1.6.4.
4. Если пакет ещё не загружен, загрузить `dist/laststicker-search-1.7.1.zip` в разделе **Пакет**.
5. Проверить: черновик **1.7.1**, опубликовано **1.6.3** (или 1.6.4, если она уже успела выйти).
6. Проверить название: **LastSticker Customizer**. Если в карточке осталось **LastSticker Search**, изменить.
7. Вставить краткое описание из `manifest.json`:
   `Поиск по диалогам и форуму, тёмная тема, фильтры коллекций и звёздочки избранного на laststicker.ru`
8. Вставить подробное описание из `store/description-1.7.1.txt`.
9. В поле **What's new** вставить `store/whats-new-1.7.1.txt`.
10. Проверить пять скриншотов в рекомендуемом порядке:
    - `screenshot-dialogs-1.7.1.png` — поиск по диалогам;
    - `screenshot-settings-1.7.1.png` — тёмная тема и настройки;
    - `screenshot-hunt-1.7.1.png` — фильтр «Я ищу»;
    - `screenshot-auction-stars-1.7.1.png` — звёздочки избранного;
    - `screenshot-highlight-1.7.1.png` — сапфировая подсветка.
    Альтернативы: `screenshot-forum-1.7.1.png`, `screenshot-theme-1.6.0.png`.
11. Проверить промо-изображения:
    - `store/promo-440x280-1.7.1.png` — маленькое;
    - `store/marquee-1400x560-1.7.1.jpg` — большое.
    Если в Dashboard остались старые изображения LastSticker Search, заменить их вручную.
12. Проверить Privacy practices:
    - remote code — No;
    - данные хранятся локально, не передаются;
    - разрешения не расширены;
    - в политике учтены страницы коллекций и аукционов, фильтр и звёздочки.
13. **Сохранить черновик.** Не отправлять на проверку без отдельного решения.

## 3. Что проверить после публикации

- Карточка и popup показывают **1.7.1**.
- На странице коллекции фильтр «Все / Я ищу» показывает только личные отметки и корректный счётчик.
- В аукционах звезда есть у активных и недавно закончившихся лотов, а также на `/auction/subscribe/`.
- Клик по звезде добавляет и убирает лот; страница избранного обновляется.
- На странице избранного и внутри лота нет второй звезды.
- Панель поиска не появляется на страницах аукционов и коллекций.
- Тёмная тема, палитра «Сапфир», быстрая прокрутка и мастер-выключатель работают.
- Политика доступна по публичному URL без входа.

## 4. После публикации

- Обновить README: убрать «подготовлена к публикации», указать актуальную версию Store.
- Обновить `docs/index.html` и `docs/privacy.html` на GitHub Pages.
- Проверить, что ссылка на ZIP ведёт на релиз 1.7.1.
- При необходимости обновить social preview и промо-материалы.

## Известные особенности

- 1.7.1 включает 1.6.4, поэтому публиковать 1.6.4 отдельно не обязательно, если 1.7.1 выйдет следующей.
- Для гостей звёзды избранного не показываются — как и на сайте.
- Завершённые лоты можно добавлять в избранное; они отображаются на странице избранного в разделе «Недавно закончились».
