# Публикация LastSticker Search 1.6.4 в Chrome Web Store

## 0. Что уже готово

- В Store опубликована **1.6.1**.
- Подготовлен пакет **1.6.4**: сапфировая подсветка, палитра «Сапфир» и сапфировые акценты в интерфейсе.
- Ветка подготовки: `release/1.6.4`, коммит `6832214`.
- Новых разрешений нет: `storage`, `scripting`, `offscreen`, `alarms`, host permissions.
- Подробное описание: `store/description-1.6.4.txt`.
- Что нового: `store/whats-new-1.6.4.txt`.
- Политика: `PRIVACY.md`, `docs/privacy.html`.

## 1. Проверить версию и собрать ZIP

```bash
git checkout release/1.6.4
npm ci
npm test -- --runInBand
npm run lint
npm run package
```

Проверить:

- в `manifest.json` и `package.json` версия **1.6.4**;
- ZIP: `dist/laststicker-search-1.6.4.zip`;
- внутри `manifest.json` в корне и версия 1.6.4;
- нет файлов трекинга и лишних разрешений.

## 2. Загрузить пакет и заполнить карточку

1. Открыть Chrome Web Store Developer Dashboard → LastSticker Search.
2. Загрузить `dist/laststicker-search-1.6.4.zip` в разделе **Пакет**.
3. Проверить: черновик **1.6.4**, опубликовано **1.6.1**.
4. Вставить описание из `store/description-1.6.4.txt`.
5. Проверить пять скриншотов в порядке:
   - диалоги;
   - форум;
   - тёмная тема;
   - настройки (`screenshot-settings-1.6.4.png`);
   - подсветка (`screenshot-highlight-1.6.4.png`).
6. Проверить Privacy practices: remote code — No; данные — локально; разрешения не расширены.
7. **Сохранить черновик.** Не нажимать «Отправить на проверку» без отдельного решения.

## 3. После публикации

- Проверить, что карточка показывает 1.6.4.
- Проверить на живом сайте:
  - сапфировую подсветку сообщения в диалоге;
  - сапфировую подсветку комментария на форуме;
  - палитру «Сапфир» в popup;
  - быструю прокрутку и мастер-выключатель.
- Обновить README и релиз, если версия в Store изменилась.

## Известное ограничение

`background.js` вставляет зависимости в активную вкладку. Если диалог или форум открыт в фоне, панель может не появиться до перезагрузки страницы. В обычном сценарии, когда пользователь находится на странице, всё работает.
