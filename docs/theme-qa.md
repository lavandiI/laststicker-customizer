# Тёмная тема и выключатель — ручная проверка

Проверять на распакованном расширении 1.7.0 в Chrome 109+ под своим аккаунтом.

## Матрица страниц

Для каждой страницы проверить выключенную и включённую тему, палитры «Графит» и «Чёрная».

- [ ] Главная `laststicker.ru`
- [ ] Каталог коллекций `/cards/`
- [ ] Коллекция и чек-лист `/cards/{collection}/`
- [ ] Карточка коллекции/лот в магазине
- [ ] Список аукциона `/auction/`
- [ ] Лот аукциона `/auction/post{id}/`
- [ ] Форум, главная `/blog/forum/`
- [ ] Тема форума `/blog/post{id}/`
- [ ] Список диалогов `/users/my_talks/`
- [ ] Отдельный диалог `/users/my_talks/{id}/`
- [ ] Архив диалогов `/users/my_talks/hide/`
- [ ] Профиль пользователя `/users/{id}/`
- [ ] Поиск по сайту `/search/?q=...`
- [ ] Формы: вход, регистрация, профиль, создание лота
- [ ] Пагинация, tooltip, autocomplete, select2, календарь, cookie consent

## Что проверить

- [ ] Нет светлых прямоугольников на тёмном фоне, кроме сторонних iframe.
- [ ] Текст читается: контраст не ниже 4.5:1 для обычного текста.
- [ ] Ссылки, hover и focus видимы.
- [ ] Таблицы, заголовки, границы и строки не сливаются.
- [ ] Разделители секций в обменном фонде (`h2` с серым фоном) не светятся белым.
- [ ] Золотые отзывы: тёмный фон, светлый читаемый текст, печать года видна.
- [ ] Блок «Информация для обмена» в профиле: тёмный фон, светлые подписи радиокнопок.
- [ ] Поиск по своим лотам на странице аукционов: тёмный фон, светлая подпись.
- [ ] Поля ввода, select, textarea, checkbox и radio читаемы.
- [ ] Кнопки «Индексировать» (`#d7e0ff` / `#2444bc`) и «Очистить» (`#993333` / белый) не изменились.
- [ ] Жёлтая подсветка результата и целевого сообщения читаема.
- [ ] Логотип, обложки, сканы и аватарки не инвертированы.
- [ ] Приглушение изображений не затрагивает иконки и аватарки.
- [ ] Переключение темы применяется без перезагрузки на всех открытых вкладках.
- [ ] После перезапуска браузера настройки сохраняются.
- [ ] Переключатель явно показывает «Включена»/«Выключена».
- [ ] Тема всегда применяется ко всему сайту и панелям поиска.
- [ ] При загрузке нет заметной белой вспышки (после первого включения).
- [ ] Нет горизонтальной прокрутки и сдвигов вёрстки.
- [ ] Popup открывается по клику на иконку, все настройки доступны с клавиатуры.
- [ ] Сброс выключает тему, выбирает графит и отключает приглушение.
- [ ] Мастер-выключатель «Расширение» выключает панель, индексацию, автообновление и тему.
- [ ] При выключении иконка в панели Chrome становится чёрной, badge очищается.
- [ ] При включении иконка возвращается, тема и панель появляются без перезагрузки.
- [ ] После перезапуска Chrome состояние выключателя и иконка сохраняются.
- [ ] Welcome page открывается после обновления и не дублируется при повторном запуске.
- [ ] При выключенном расширении Welcome page показывает кнопку «Включить расширение» и включает его.
- [ ] На длинной странице справа снизу видны кнопки ↑ и ↓; на короткой странице их нет.
- [ ] Кнопка ↑ переводит в начало страницы, ↓ — в конец; на краях страницы кнопка неактивна.
- [ ] В светлой теме кнопки белые с рамкой `#d7e0ff` и синими стрелками.
- [ ] В тёмной теме и палитре «Чёрная» кнопки используют тёмный фон и светлые стрелки.
- [ ] При выключении мастер-выключателем кнопки исчезают, при включении возвращаются.
- [ ] В ZIP есть `scroll-widget.js` и `scroll-widget.css`.
- [ ] В сообщении трек-номер становится ссылкой; при выключенном маршруте ссылка ведёт на официальный сайт.
- [ ] После включения «Маршрут по трек-номеру» и выдачи необязательных разрешений клик по номеру раскрывает карточку под сообщением.
- [ ] В карточке видны статус, дата, событие, место и индекс; работают «Обновить» и «На сайте».
- [ ] Повторный клик по номеру сворачивает карточку.
- [ ] Маршрут работает для Почты России и Белпочты; при 429 показывается понятное сообщение.
- [ ] В тёмной теме карточка и ссылка читаемы.
- [ ] При выключении мастер-выключателем ссылки и карточки исчезают, при включении возвращаются.
- [ ] В ZIP есть `tracking-core.js`, `tracking-api.js`, `tracking.js` и `tracking.css`.
- [ ] В ZIP есть `icons/black/*` и `welcome.html/css/js`.

## Известные ограничения

- Реклама внутри сторонних iframe не перекрашивается.
- Некоторые очень старые страницы с нестандартными инлайновыми стилями могут требовать точечных правил; если тема ломает страницу, выключите её и пришлите URL.
- Тема не скрывает рекламу и не меняет структуру сайта.
- Физический размер IndexedDB и `chrome.storage.local` не связан с темой.
