# LastSticker Customizer - Changelog

## Правила ведения CHANGELOG

### Структура записей

```
### [Версия] - Дата
#### Добавлено
- Новая функциональность

#### Исправлено
- Исправленные баги

#### Изменено
- Изменения в существующем функционале

#### Удалено
- Удаленный функционал
```

### SemVer (Semantic Versioning)

- **MAJOR** (1.0.0 → 2.0.0) - несовместимые изменения API
- **MINOR** (1.0.0 → 1.1.0) - новый функционал с обратной совместимостью
- **PATCH** (1.0.0 → 1.0.1) - исправления багов

### Процесс

1. Все изменения добавлять в раздел `[Unreleased]`
2. При релизе переименовать в `[Версия] - Дата` и обновить версию в `manifest.json`

## [1.8.0] - 2026-11-19

#### Исправлено

- Даты форума и списка диалогов распознают сокращения «май» и «сент», а в панели диалогов кириллический месяц больше не отбрасывается из-за регулярного выражения
- Подсветка запроса работает для запросов с `&`, `<`, `>` и кавычками: запрос экранируется так же, как текст результата
- Тёмная тема: снимок настроек, пришедший с опозданием, больше не откатывает только что применённую тему
- Звёздочки в аукционах больше не тянут список избранного при каждом открытии: загрузка отложена до простоя страницы, набор кешируется в `sessionStorage` на 5 минут, а глубина обхода снижена с 20 страниц до 3
- Счётчик сообщений в списке диалогов больше не принимает дату вида `12/2024` за количество сообщений: значение читается из текста ячейки с проверкой на дату
- Экран «Что нового» понимает устаревшую запись темы и не показывает зашитый номер версии, если манифест недоступен
- Тёмная тема: счётчик непрочитанных больше не печатается белым по оранжевому (2,8:1) — текст тёмный, контраст 6,6:1
- Тёмная тема: ячейки с неизвестным инлайновым фоном больше не оставляют приглушённый серый текст на светлом фоне; известные оттенки «есть / ищу / нужно» перекрашиваются через общие токены
- Печать тёмной темы снова читаема: палитра сбрасывается на светлую (было — светлый текст на белой бумаге, ~1,2:1)
- Палитры «Чёрная» и «Сапфир» перекрашивают акцентные поверхности (выделенные строки, новые комментарии, форумные цитаты, счётчики), а не оставляют графитовые синие и зелёные пятна
- Ссылки в результатах форума валидируются при записи: в `href` попадают только адреса `laststicker.ru` и относительные пути, остальное отбрасывается
- Звёздочки избранного в аукционах: двойной клик по двум строкам одного лота больше не отправляет два запроса в toggle-эндпоинт (они взаимно отменялись) — запрос на лот идёт один
- Неудачный клик по звёздочке теперь объясняет причину в углу страницы («сайт ответил 403», «сайт не подтвердил изменение», «нет связи с сайтом») вместо молчаливого `console.warn`
- Переход к сообщению из «старого» результата (без `messageId`) больше не качает страницы диалога по одной: запросы идут пачками по 10, ограничены 100 страницами и шестью секундами, показывают прогресс и прекращаются, если пользователь кликнул по другому результату
- Результат индексации теперь пишется в `chrome.storage.local`: панель обновляет статистику, статус и ошибки по подписке на хранилище, поэтому перезапуск service worker или потерянный ответ больше не оставляют кнопку в состоянии «Индексация…»
- Настройки темы больше не сбрасываются в дефолтные при ошибке чтения хранилища: частичное сохранение использует тему, которую popup уже показывает, и при неудачном чтении показывает «Не удалось сохранить» вместо тихой записи дефолтов
- `chrome.runtime.sendMessage` из popup при закрытом порте service worker больше не даёт необработанного отказа промиса
- Сбой записи метаданных (время индексации, флаг полного индекса, отчёт автообновления) больше не превращает успешно сохранённый индекс в сообщение об ошибке
- Текст ошибки записи индекса теперь сообщает, сколько сообщений собрано и что уже сохранённый индекс не изменён
- Подсказка к размеру индекса больше не ссылается на снятый лимит `chrome.storage.local`, а предупреждает о замедлении поиска
- Фильтр «Я ищу» больше не портит счётчик чек-листа: исходный текст запоминается и восстанавливается при выключении, а при неизвестном формате счётчика показывается только число видимых строк без выдуманного «из N»
- Фильтр «Я ищу» больше не исчезает после перерисовки таблицы: контрол пересоздаётся по `MutationObserver`, выбранный режим сохраняется, а ожидание таблицы больше не ограничено пятью секундами

#### Изменено

- Удалён неиспользуемый userscript-режим панели и дублирующий парсер в content script: разбор страниц идёт только через расширение (content.js — 878 → 233 строки, три копии парсера из четырёх)
- Тёмная тема: кэш первого кадра обновляется и при выключенном расширении, поэтому страница больше не мигает тёмным перед переходом на светлую
- Отладочные сообщения панели, парсера и хранилища больше не пишутся в консоль по умолчанию (флаг `DEBUG_LOG` в файле); из service worker убран лог на каждое входящее сообщение
- Поле поиска объявлено `combobox` с `aria-expanded`, который меняется вместе со списком; когда результатов нет, `role="listbox"` снимается, чтобы подсказка не попадала в список без опций
- Результаты поиска размечены как список (`listbox` → `group` → `option`), поэтому навигация стрелками и выбранный результат корректно объявляются скринридером
- Поиск по форуму останавливает сканирование, как только нашёл страницу результатов плюс одно совпадение: при большом числе совпадений запрос больше не проходит по всему индексу, а панель вместо придуманного итога показывает «Показаны первые N совпадений»
- Панель поиска кэширует разобранный индекс: ввод в строке поиска больше не перечитывает и не парсит все сообщения заново, кэш сбрасывается при сохранении, очистке и изменении индекса из другого контекста
- Форумный поиск: «Показать ещё» догружает следующую страницу по `offset` вместо повторного чтения всего набора результатов, поэтому размер ответа не растёт с числом показанных совпадений
- Offscreen-индексатор раз в 10 секунд отправляет heartbeat в background, чтобы service worker не засыпал между батчами и не перезапускался посреди индексации
- Состояние запущенной индексации теперь хранится в `chrome.storage.session`: после перезапуска service worker расширение узнаёт о работающей задаче (проверяя её у offscreen-документа) вместо того, чтобы терять прогресс и результат
- Добавлено разрешение `unlimitedStorage`: индекс диалогов больше не упирается в квоту `chrome.storage.local` (5–10 МБ в зависимости от версии Chrome), из-за которой на большом архиве терялась вся работа индексации
- Обоснование `unlimitedStorage` добавлено в политику конфиденциальности (RU/EN) и в листинг Chrome Web Store
- Версия Manifest и пакета — 1.8.0

### [1.1.0] - 2026-03-07

- Поиск внутри отдельного диалога/разговора (страница /users/my_talks/{id})
- Панель поиска на странице диалога с отображением количества сообщений
- Автоматическая загрузка всех страниц разговора для полной индексации
- Парсинг изображений в сообщениях (функция parseImagesFromHtml)
- Unit-тесты для функции парсинга изображений
- Добавлены иконки расширения всех размеров (16, 32, 48, 128px)

#### Исправлено

- Исправлены синтаксические ошибки в inline-panel.js и inline-ui.js (сломанные вызовы функций)
- Добавлен флаг InlinePanelReady для корректной инициализации панели
- Исправлена ошибка "InlinePanel still not ready after injection"
- Добавлена логика повторных попыток (retry) при загрузке зависимостей и inline-panel (до 10 попыток с интервалом 200ms)

#### Изменено

- Парсинг сообщений: изображения извлекаются и индексируются всегда (даже при наличии текста)
- Изображение добавляется к тексту сообщения в формате `[Image: src1, src2, ...]`
- Улучшен парсинг сообщений (извлечение ID, timestamp, партнёра)
- Заменена навигация через chrome.tabs.update на прямые fetch() вызовы при индексации
- Улучшена скорость и надежность процесса индексации
- Оптимизирована локальная индексация при входе в диалог: используются закэшированные сообщения из глобальной индексации вместо повторного сетевого запроса

### [1.0.1] - 2026-03-07

#### Исправлено

- Статистика (кол-во диалогов/сообщений) теперь обновляется без перезагрузки страницы после индексации
- Панель теперь отображается только на странице /users/my_talks/, а не на /users/my_talks/hide/
- Исправлено overflow для поля поиска

#### Изменено

- Обновлены стили панели под дизайн сайта (шрифты, цвета, размеры)
- Кнопка "Индексировать" теперь более тёмного синего цвета
- Кнопка "Очистить" теперь менее яркого красного цвета
- Цифры диалогов и сообщений теперь того же цвета, что и кнопка "Индексировать"
- Поисковый ввод теперь с обычным (не жирным) шрифтом

#### Удалено

- Убрана функция перехода в диалог при клике или Enter на результате поиска

## Краткий справочник проекта

> Chrome Extension для индексации и поиска сообщений на laststicker.ru

### Технологии

- **Тип**: Chrome Extension (Manifest V3)
- **Язык**: JavaScript (ES6+)
- **Линтинг**: ESLint
- **Форматирование**: Prettier
- **Хранение**: localStorage (сообщения) и chrome.storage.local (настройки)
- **Тестирование**: Jest

### Основные файлы

| Файл                                       | Назначение                                        |
| ------------------------------------------ | ------------------------------------------------- |
| [`manifest.json`](manifest.json:1)         | Конфигурация расширения                           |
| [`background.js`](background.js:1)         | Service Worker (фоновый скрипт)                   |
| [`content.js`](content.js:1)               | Content script (извлечение сообщений со страницы) |
| [`inline-panel.js`](inline-panel.js:1)     | Встроенная панель на странице                     |
| [`inline-ui.js`](inline-ui.js:1)           | UI-компоненты встроенной панели                   |
| [`inline-storage.js`](inline-storage.js:1) | Работа с хранилищем для inline-панели             |
| [`inline-styles.css`](inline-styles.css:1) | Стили встроенной панели                           |
| [`tests/`](tests/)                         | Unit-тесты                                        |

### Команды

```bash
npm install      # Установка зависимостей
npm run lint     # Запуск ESLint
npm run format   # Запуск Prettier
npm test         # Запуск Jest
```
